# Viewing scans

Open **Scans**, click a row. Status `COMPLETED` means evidence was loaded and policies ran. `FAILED` shows `error_message` on the job.

Use **Approve baseline** once a scan represents the accepted posture for that repository.

From the same page you can download a signed **evidence pack**, the
**CRA/NIST audit zip**, and see the **agility score**, **work-orders**,
and **drift-gate** decision. See [evidence-pack.md](evidence-pack.md)
and [ci-drift-gate.md](ci-drift-gate.md).
