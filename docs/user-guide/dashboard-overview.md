# Dashboard

The dashboard is a single-page app served at `/`.

- **Overview** — scan counts, compliance totals, estate CBOM roll-up
- **CBOM** — CycloneDX inventory, search, import, portfolio export, diff
- **Scans** — every completed or failed session
- **Scan detail** — findings table
- **Finding detail** — snippet, hashes, rule-by-rule evaluation
- **New scan** — local path or git URL
- **Drift** — acknowledge open events
- **Agility** — 6-factor scores and migration waves
- **Exceptions** — request / approve / revoke policy exceptions
- **Vendors** — questionnaire-driven crypto risk
- **OT / ICS** — passive device and protocol inventory
- **Analytics** — trends, heat map, PQC forecast, executive roll-up
