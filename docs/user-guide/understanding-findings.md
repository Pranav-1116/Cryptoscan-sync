# Understanding findings

Each finding is a cryptographic API call, not a vulnerability score.

- **Algorithm / mode / key size** — as parsed, then normalized
- **Compliance** — `PASS` / `FAIL` / `WARN` from the policy engine
- **content_hash / chain_hash** — 64-char SHA-256 hex
- **Rules evaluated** — every enabled baseline rule, including `NOT_APPLICABLE`

A `FAIL` on BASELINE-001 means the algorithm is in the forbidden list. A `FAIL` on BASELINE-004 means a hardcoded key was detected. The message is generated by the condition, not by a model.
